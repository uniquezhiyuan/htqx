**海天气象（[https://htqx.cn/](https://htqx.cn/)）** 是一个致力于提供高精度、高时空分辨率气象数据服务的综合性数据平台。本项目作为海天气象的数据获取与可视化开源方案，旨在帮助科研人员、气象爱好者及行业开发者快速接入海天气象 API，迅速获取超长时间尺度、超高时空分辨率的历史天气数据和天气预报数据，高效完成从原始数据解析、时空重采样到专业气象图表绘制的全流程工作。

本文档将详细向用户展示以下内容：
* 通过API调取全国任意市区县任意年份的逐小时历史天气数据
* 通过API调取全国任意市区县未来240小时的逐小时天气预报数据
* 通过API调取全国任意区域的逐小时网格预报数据
* 以上所有数据的可视化图表生成

[![image](./figures/海天气象主页.png)](https://htqx.cn/)


海天气象数据信息服务平台主要提供以下四大类气象与环境数据服务：
* **历史天气数据**：提供长期连续的小时级地面观测与再分析气象要素记录，支撑气候变化研究与历史灾情复盘。
* **城市天气预报数据**：覆盖全国各级行政区划的精细化未来10日逐小时天气预报，满足日常出行与城市运行调度需求。
* **网格天气预报数据**：ECMWF的高分辨率格点场数据，适用于区域气象分析与精细化行业建模。
* **空气质量数据**：提供历史小时级空气质量指数（AQI）与主要大气污染物浓度监测数据，助力环境治理与健康预警。

超过40+种气象变量，覆盖气温、气压、湿度、风力、降水、云量、能见度、天气现象、辐射、土壤温湿度、大气动力指数、大气水汽条件等全部气象要素。

有关数据说明和API示例代码以及全部气象变量的详细说明请参考 **[海天气象官方开发文档](https://htqx.cn/meteo/doc)**。

## 🛠️ 环境准备与项目结构

可以使用下列命令直接将仓库克隆到本地后运行：

```bash
git clone https://github.com/uniquezhiyuan/htqx.git
```

在运行本项目的可视化脚本前，请确保您的 Python 环境（推荐 3.8 及以上版本）已安装以下核心依赖库：

```bash
pip install requests pandas numpy matplotlib seaborn cartopy scipy
```

项目目录结构及重要文件说明：
* `/src/`：程序源代码目录。
* `/data/`：统计分析数据CSV文件输出目录。
* `/figures/`：生成的气象数据可视化图表存放目录。
* `/doc/`：说明文档目录。

## 1. 历史天气数据

### 1.1 API 获取方式

通过向海天气象数据服务器发送下列 `GET` 请求即可获取指定地点任意年份的逐小时历史气象数据，包含40+种气象变量8760个时次数据。

**API 通用格式 URL：**
```http
https://htqx.cn/meteo/api/history/yearly/{city_name}/{year}/{api_key}
```
**API 须提供3个可变参数:**
- `city_name` 全国市区县任意地名
- `year` 2000年至今任意年份
- `api_key` 海天气象用户专属26位 API Key，可以在[个人中心](https://htqx.cn/meteo/profile/)查看并复制

**一个完整的API URL示例如下（可直接复制测试）：**
```http
https://htqx.cn/meteo/api/history/yearly/西安市/2025/2js7rY7j89JgbNH76Ggh7TF5r6
```

### 1.2 返回数据类型与结构

接口返回标准 `UTF-8` 编码的 **JSON** 数据，共包含 **40 个核心气象变量**（气温、体感温度、相对湿度、露点温度、降水量、气压、风速、风向、云量、能见度、短波辐射、天气现象代码等），详见气象要素图或开发文档。

数据结构采用时序数组的扁平化嵌套结构，便于直接转换为 `Pandas DataFrame`，以下是局部数据示例：
```json
{
  "date": [
    "2025-01-01T00:00:00",
    "2025-01-01T01:00:00",
    "2025-01-01T02:00:00"
  ],
  "temperature_2m": [-0.8, -1.2, -1.5],
  "relative_humidity_2m": [78, 81, 83],
  "dew_point_2m": [-4.2, -4.1, -4.0],
  "precipitation": [0.0, 0.0, 0.0],
  "rain": [0.0, 0.0, 0.0],
  "snowfall": [0.0, 0.0, 0.0],
  "weather_code": [0, 0, 0],
  "pressure_msl": [1028.4, 1028.1, 1027.9],
  "surface_pressure": [978.2, 977.9, 977.7],
  "cloud_cover": [12, 15, 18],
  "et0_fao_evapotranspiration": [0.0, 0.0, 0.0],
  "vapour_pressure_deficit": [0.13, 0.11, 0.10],
  "wind_speed_10m": [5.4, 5.8, 6.1],
  "wind_speed_100m": [11.2, 11.9, 12.4],
  "wind_direction_10m": [65, 68, 70],
  "wind_direction_100m": [72, 75, 78],
  "wind_gusts_10m": [11.5, 12.2, 13.0],
  "shortwave_radiation": [0.0, 0.0, 0.0],
  "direct_radiation": [0.0, 0.0, 0.0],
}
```

**返回数据说明：**

- 组织形式：列式存储（Columnar JSON），以气象要素字段名为键（Key），对应值为长度 8760（平年）或 8784（闰年）的一维数组，与 date 时间戳数组按索引一一对应，可直接通过 pd.DataFrame(data) 转换为 Pandas 数据框。

- 包含维度：1 个 ISO-8601 时间轴（date）+ 40 个逐小时气象变量，涵盖温湿压、降水降雪、云量分层、风速风向、土壤墒情及短波/直接/散射太阳辐射。时间为北京时间。

### 1.3 历史天气数据处理与可视化示例

克隆本项目后在命令行运行以下命令即可获取全国任意市区县任意年份的逐小时历史天气数据，并绘制成精美的统计分析决策报表。

```bash
cd ./src
python history_single_year.py
```

### 1.4 行业应用场景

* **生态与水文**：分析流域历史降水极值与蒸发量平衡，支撑水库防洪调度模型率定与区域生态环境演变研究。

## 2. 网格预报数据

### 2.1 API 获取方式

通过向海天气象数据服务器发送下列 `GET` 请求即可获取指定地点任意未来10日任意时次任意气象变量全国0.1°网格预报数据，包含20+种气象变量1个给定时次数据。

**API 通用格式 URL：**
```http
https://htqx.cn/meteo/api/forecast/grid/{time}/{meteo_type}/{api_key}
```
**API 须提供3个可变参数:**
- `time` 预报时间，未来10日任意时次，格式为YYYYMMDDHH
- `meteo_type` 气象变量名称，可以对照[开发文档](https://htqx.cn/meteo/doc/)查看所有支持的气象变量名称
- `api_key` 海天气象用户专属26位 API Key，可以在[个人中心](https://htqx.cn/meteo/profile/)查看并复制

**一个完整的API URL示例如下（可直接复制测试）：**
```http
https://htqx.cn/meteo/api/forecast/grid/2026112612/temperature_2m/2js7rY7j89JgbNH76Ggh7TF5r6
```

### 2.2 返回数据类型与结构

接口返回标准 `UTF-8` 编码的 **JSON** 数据，共包含 **1 个指定气象变量1个指定未来时次的全国0.1°二维网格数据**。网格形状为400×630.

数据结构采用“元数据 + 时序数组”的扁平化嵌套结构，便于直接转换为 `Pandas DataFrame`，以下是局部数据示例：
```json
{
  "metadata": {
    "time": "2026-11-26T12:00:00.000000000",
    "variable": "2-meter Temperature",
    "units": "°C",
    "nodata_value": -9999.0,
    "bounds": {
      "lat_min": 15.0,
      "lat_max": 55.0,
      "lon_min": 73.0,
      "lon_max": 136.0
    },
    "shape": [401, 631]
  },
  "lats": [55.0, 54.9, 54.8, "...共401个纬度点(步长-0.1°)", 15.1, 15.0],
  "lons": [73.0, 73.1, 73.2, "...共631个经度点(步长+0.1°)", 135.9, 136.0],
  "data": [
    [-1.9, -2.0, -1.9, "...共631列(对应lons)", -13.1, -12.8],
    [-1.9, -1.9, -1.9, "...共631列(对应lons)", -15.5, -14.9],
    "...共401行(对应lats)"
  ]
}
```

**返回数据说明：**

* metadata（元数据）：声明预报时次（time）、要素名称（variable）、单位（units）、缺测值标识（nodata_value: -9999.0）、经纬度范围（bounds，覆盖中国及周边 15°N–55°N, 73°E–136°E）以及二维网格维度（shape: [401, 631]，对应 0.1° 空间分辨率）。

* lats / lons（坐标一维数组）：lats 从 55.0 递减至 15.0（长度 401），lons 从 73.0 递增至 136.0（长度 631）。

* data（二维数值矩阵）：形状为 [401, 631] 的嵌套数组，data[i][j] 表示纬度 lats[i]、经度 lons[j] 处的预报值，可直接转为 NumPy 数组或 xarray.DataArray 进行空间插值与填色绘图。

### 2.3 网格数据处理与可视化示例

克隆本项目后在命令行运行以下命令即可获取全国任意时次任意气象变量的网格预报数据，并绘制成精美的统计分析决策报表。

```bash
cd ./src
python grid_forecast_single.py  # 绘制单一气象变量的网格预报图
python grid_forecast_all.py  # 绘制全部气象变量某一时次的网格预报图
```

 `grid_forecast_single.py` 从海天气象 API 获取未来 10 日（240 小时）内指定时次与单变量的 0.1° 全国网格预报数据，并按自定义经纬度方格裁剪后生成高分辨率空间等值线图。它在输入校验与数据获取阶段严格检查预报时次格式及未来 10 日有效期、经纬度范围与 21 个支持变量，校验二维网格形状并屏蔽 -9999 缺测值，同时支持升/降序坐标轴自适应裁剪与省界 GeoJSON 自动下载及本地缓存（data/china_provinces.geojson）；在可视化渲染阶段针对气温、降水、湿度、风速、风向、辐射及 WMO 天气现象代码匹配定制色板与分级等值线，叠加省级行政边界、半透明省名标注、等比例正方形经纬度网格及起报/预报时效说明，便于区域气象预警、能源调度与空间分布分析。

 修改代码顶部的经纬度范围和时次可以指定全国任意区域、任意时次、任意气象变量绘图：
 ```python
 API_KEY = "2js7rY7j89JgbNH76Ggh7TF5r6"  # 请在海天气象个人中心查看26位 API Key：https://htqx.cn/
FORECAST_TIME = "2026112816"  # 格式 YYYYMMDDHH，须在未来 10 日内
VARIABLE = "temperature_2m"  # 须为气象变量列表中的 21 个变量之一
LON_MIN = 73.0  # 区域西边界经度 (°E)，建议范围 73.0 ~ 136.0
LON_MAX = 136.0  # 区域东边界经度 (°E)，建议范围 73.0 ~ 136.0
LAT_MIN = 18.0  # 区域南边界纬度 (°N)，建议范围 15.0 ~ 55.0
LAT_MAX = 54.0  # 区域北边界纬度 (°N)，建议范围 15.0 ~ 55.0
 ```

## 3. 城市天气预报数据

### 3.1 API 获取方式

通过向海天气象数据服务器发送下列 `GET` 请求即可获取指定地点任意（全国市区县）未来10日逐小时天气预报数据，包含20+种气象变量240个时次数据。

**API 通用格式 URL：**
```http
https://htqx.cn/meteo/api/forecast/daily/{city_name}/{year}/{month}/{day}/{api_key}
```

**API 须提供5个可变参数:**
- `city_name` 地名参数，支持全国3191个市区县全名
- `year` `month` `day`  日期参数，默认为当前日期，也可查询过去一个月内任意日期的未来10日天气预报
- `api_key` 海天气象用户专属26位 API Key，可以在[个人中心](https://htqx.cn/meteo/profile/)查看并复制

**一个完整的API URL示例如下（可直接复制测试）：**
```http
https://htqx.cn/meteo/api/forecast/daily/武汉市/2026/11/24/2js7rY7j89JgbNH76Ggh7TF5r6
```

### 3.2 返回数据类型与结构

接口返回标准 `UTF-8` 编码的 **JSON** 数据，共包含 **1 个指定城市未来240个时次的天气预报数据**。气象变量数量为21种。数据时间为北京时间。

数据结构采用“时序数组”的扁平化嵌套结构，便于直接转换为 `Pandas DataFrame`，以下是局部数据示例：
```json
{
  "date": {
    "0": "2026-11-24 00:00:00",
    "1": "2026-11-24 01:00:00",
    "2": "2026-11-24 02:00:00",
    "...共240个逐小时索引(0~239)": "...",
    "239": "2026-12-03 23:00:00"
  },
  "temperature_2m": {
    "0": 11.0,
    "1": 10.6,
    "2": 10.0,
    "...对应各小时2米气温(°C)": "...",
    "239": 16.1
  },
  "relative_humidity_2m": {
    "0": 71.3,
    "1": 71.2,
    "2": 70.2,
    "...对应各小时2米相对湿度(%)": "...",
    "239": 94.0
  },
  "dew_point_2m": {
    "0": 6.1,
    "1": 5.5,
    "2": 4.9,
    "...其余气象要素字段均以\"0\"~\"239\"字符串索引对齐": "..."
  }
}
```

**返回数据说明：**

* 索引映射形式：顶层键为时间轴 "date" 与各气象要素名称，每个键对应一个以字符串索引 "0" 到 "239" 为键的字典，覆盖未来 10 日（240 小时）逐小时序列。

* 对齐方式：各变量字典通过相同的字符串索引（如 "0"、"1"、"2"）与 "date" 中的时间戳一一对应，便于按时次提取或转换为表格/时序数组进行日统计或可视化。

### 3.3城市预报数据处理与可视化示例

克隆本项目后在命令行运行以下命令即可获取全国任意地点未来10日逐小时预报数据，并绘制成精美的统计分析决策报表。

```bash
cd ./src
python city_forecast.py  
```

 `city_forecast.py` 调用海天气象逐日天气预报 API 获取指定城市未来 10 日（240 小时、北京时间）的逐小时预报数据，并生成多板块天气预报综合图。它在数据获取与汇总阶段校验起报日期并解析气温、天气现象代码、10 米风速风向、海平面气压、降水、短波辐射、总云量、能见度及相对湿度等要素，按自然日统计高低温、正午天气现象、圆周平均风向、累积降水及 ≥0.1 mm 连续降水时段；在可视化渲染阶段顶部展示最接近当前北京时间的实况/预报卡片，中部生成嵌入矢量天气图标的 10 日逐日预报汇总表，下部绘制叠加每日高低极值标记的逐小时气温趋势线与“日期 × 小时”降水日历热力格，且天气图标完全由 matplotlib 几何图元矢量绘制，零外部图标或网络依赖，直观适配出行规划、城市运维与气象业务展示。

### 3.4 行业应用场景

* **城市智慧交通与物流**：结合逐小时降水概率与风力等级，动态调整同城即时配送运力调度、外卖超时预警阈值及共享单车潮汐投放策略。
* **电力负荷预测**：城市商业与居民空调制冷/采暖负荷与逐小时体感温度高度相关，精细化城市温度预报可直接输入电网短期负荷预测模型。
* **智慧农业与设施园艺**：为城郊现代农业大棚提供精确的夜间低温与强对流天气预警，指导农户及时启闭卷帘、通风口或采取临时加温措施。
